# Changelog

All notable changes to Spàrsh Browser will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-06

### Added
- Initial release of Spàrsh Browser
- Modern, clean user interface with dark theme
- Multi-tab browsing with smooth transitions
- Smart address bar with search and URL input
- New tab page with customizable shortcuts
- Bookmarks manager with visual cards
- Browsing history with search functionality
- Downloads manager with progress tracking
- Comprehensive settings panel
- Built-in privacy features
- Cross-platform support (Windows, Linux, Android)
- Keyboard shortcuts for common actions
- Custom Spàrsh branding and design
- MIT License for open-source distribution

### Features
- **Tab Management**
  - Create, switch, and close tabs
  - Tab titles and favicons
  - Smooth tab transitions
  
- **Navigation**
  - Back/Forward navigation
  - Reload functionality
  - Home button
  - Address bar with auto-complete
  
- **Bookmarks**
  - Add/Remove bookmarks
  - Visual bookmark cards
  - Bookmarks bar
  - Favicon support
  
- **History**
  - Automatic history tracking
  - Search history
  - Clear history
  - Grouped by date
  
- **Downloads**
  - Download tracking
  - Progress monitoring
  - Open downloaded files
  - Show in folder
  
- **Settings**
  - Default search engine selection
  - Home page customization
  - Privacy toggles
  - Appearance options
  - Download preferences
  
- **Privacy & Security**
  - Ad blocker (ready for implementation)
  - Do Not Track
  - Private browsing mode support
  - Secure connections indicator

### Technical
- Built with Electron 28
- Chromium-based rendering engine
- BrowserView for web content
- electron-store for data persistence
- Cross-platform desktop support
- Android support via Capacitor

### Design
- Gradient brand colors (Indigo to Pink)
- Dark theme by default
- Smooth animations and transitions
- Responsive layout
- Modern, minimalist UI
- System font stack
