## 🚀 How to Use

### Quick Start (3 steps):

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run the Browser**
   ```bash
   npm start
   ```

3. **Start Browsing!**
   - The browser will open automatically
   - Type URLs or search queries in the address bar
   - Create tabs, bookmark pages, explore!

### Building for Production:

**Windows:**
```bash
npm run build:win
```
→ Creates installer in `dist/` folder

**Linux:**
```bash
npm run build:linux
```
→ Creates AppImage in `dist/` folder

**Android:**
```bash
npm run build:android
```
→ Creates APK in `android/app/build/outputs/apk/release/`
