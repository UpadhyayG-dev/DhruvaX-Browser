# Spàrsh Browser Features

## Core Browser Features

### 🗂️ Tab Management
- **Multiple Tabs**: Open and manage multiple tabs simultaneously
- **Tab Switching**: Quick keyboard shortcuts (Ctrl+Tab, Ctrl+Shift+Tab)
- **Close Tabs**: Individual tab close buttons with Ctrl+W shortcut
- **New Tab**: Ctrl+T to open a new tab
- **Tab Favicons**: Display website icons in tabs
- **Active Tab Highlighting**: Visual indication of current tab

### 🔍 Smart Address Bar
- **Unified Search/URL**: Single bar for both searching and entering URLs
- **Auto-Detection**: Automatically determines if input is a URL or search query
- **HTTPS by Default**: Automatically adds HTTPS to URLs
- **Search Integration**: Works with Google, Bing, DuckDuckGo, and Brave
- **Focus Shortcut**: Ctrl+L to quickly access address bar
- **Security Indicator**: Lock icon for HTTPS connections

### 🏠 New Tab Page
- **Quick Access Shortcuts**: Customizable shortcuts to favorite sites
- **Search Bar**: Instant search from new tab
- **Beautiful Design**: Modern gradient background with smooth animations
- **Quick Links**: Pre-configured popular sites (Google, YouTube, GitHub, etc.)
- **Add Custom Shortcuts**: Personalize with your own bookmarks

### 📑 Bookmarks Manager
- **Save Bookmarks**: Quick bookmark with Ctrl+D
- **Visual Cards**: Beautiful card-based bookmark display
- **Organize**: Group and manage bookmarks
- **Favicon Display**: Visual icons for easy identification
- **Bookmarks Bar**: Quick access bar below address bar
- **Edit/Delete**: Full management capabilities
- **Search**: Find bookmarks quickly

### 📜 History
- **Auto-Tracking**: Automatically saves browsing history
- **Date Grouping**: Organized by Today, Yesterday, and older dates
- **Search History**: Find past visits quickly
- **Visit Times**: See exact time of each visit
- **Clear History**: Remove all or selective history
- **Quick Access**: Ctrl+H keyboard shortcut

### 📥 Downloads Manager
- **Download Tracking**: Monitor all downloads
- **Progress Bars**: Real-time download progress
- **Status Indicators**: See download state (downloading, completed, failed)
- **Open Files**: Launch downloaded files directly
- **Show in Folder**: Navigate to download location
- **Download History**: Keep track of past downloads

### ⚙️ Settings Panel
- **Search Engine**: Choose default (Google, Bing, DuckDuckGo, Brave)
- **Home Page**: Customize startup page
- **Privacy Controls**: Ad blocker, Do Not Track, clear on exit
- **Appearance**: Dark mode, bookmarks bar visibility
- **Download Settings**: Choose download location, ask before saving
- **About Section**: Version info and updates

## Privacy & Security Features

### 🔒 Privacy
- **No Tracking**: Spàrsh doesn't collect user data
- **Do Not Track**: Send DNT headers to websites
- **Clear on Exit**: Auto-clear browsing data (optional)
- **Private Mode**: Incognito browsing support
- **Ad Blocker**: Built-in ad blocking (ready for implementation)

### 🛡️ Security
- **HTTPS Enforcement**: Prefer secure connections
- **Secure Indicator**: Visual HTTPS lock icon
- **Sandboxed Tabs**: Isolated browsing contexts
- **Safe Downloads**: Scan downloads for threats

## Navigation Features

### ⬅️ Navigation Controls
- **Back Button**: Return to previous page
- **Forward Button**: Go to next page in history
- **Reload**: Refresh current page (Ctrl+R)
- **Home Button**: Return to new tab page
- **Stop Loading**: Cancel page load
